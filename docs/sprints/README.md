## Working agreement

- **Board columns:** Todo → In Progress → In Review → Done.
- **Definition of Ready:** the issue has a user story, acceptance criteria and a MoSCoW priority.
- **Definition of Done:** all acceptance criteria are met and covered by tests, CI is green,
  the change was merged into `main` through a pull request, and the issue is closed by the PR.
- **Estimation:** story points (1, 2, 3, 5, 8) based on relative effort.
- **Roles:** this is an individual project, so the author acts as Product Owner, Scrum Master and
  developer. Sprint planning, review and retrospective are short written sessions recorded below.
